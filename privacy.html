Privacy Policy

Applies to the personal application "rclone backup" (home).

What Google user data is accessed

With the owner's consent, the application accesses the owner's own Google Drive to create, update, move and delete backup files in a backup folder, and reads file names, sizes and modification times to compare them with OneDrive.

How the data is used

The data is used only to keep the backup copy in Google Drive identical to the owner's OneDrive files. It is not used for advertising, profiling or any other purpose.

Storage and sharing

All processing happens on the owner's own PC. Files pass from OneDrive to Google Drive through the PC's memory only. The sign-in tokens are stored only in a configuration file on that PC. No data is sent to any other server or person, and no data is sold or shared.

Users

The application is used only by its owner and is not offered to anyone else.

Removing access

The owner can revoke access at any time at Google Account → Third-party connections.

Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
